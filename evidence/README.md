# Execution evidence

Snapshots of runs against live services, kept in the repo for judges. All data is synthetic demo data; payments are Stripe **test mode**; anchors are on a **local** FISCO BCOS chain. Regenerate with the commands below (output goes to `logs/`, which is not committed).

## `run-2026-10-17T17-27Z/` (`npm run evidence`)

- `summary.md`: D1–D6, D4b and A1–A9 with expected vs actual result and evidence (Stripe test PaymentIntent IDs, FISCO BCOS tx hashes, models used). Result 16/16.
- `audit-tasks.jsonl`, `audit-attacks.jsonl`: the hash-chained audit log of each run. Each row has `prev_hash` and `hash = sha256(prev_hash, ts, case_id, actor, action, input_sources, decision, result)`; the chain can be re-verified with `verifyChain` (`src/server/audit.ts`).
- The SQLite files of the run are not included: they are regenerated by the command and contain the (synthetic) PII token table.

Limits: Stripe IDs can only be looked up in the team's Stripe test dashboard. The FISCO BCOS chain is local, so its tx hashes are verifiable by rerunning the chain and the command, not on a public explorer.

## `baseline-2026-10-18/` (`npm run baseline`)

Same bill and estimate given to a generic LLM chat with no guardian pipeline vs the guardian explanation. Both sides used `groq:openai/gpt-oss-120b`, 3 trials. The guardian's 40 item readings came from an earlier cached reader run (Gemini); the generic chat received the same scrubbed document text.

- `trialN-baseline.md` / `trialN-guardian.md`: raw outputs.
- `metrics.json`: computed by code from the answer key (`src/server/fixtures/answer-keys.ts`). Words quoted from the documents and numbers printed in them are not counted as invented. "Numbers not traceable" are numbers that appear neither in the documents nor in the computed facts; some were spot-checked and found wrong (e.g. drug total CNY 2,534 and 2,224 vs true 1,702), the rest are not individually verified.

| Metric | Guardian (3 trials) | Generic chat (3 trials) |
|---|---|---|
| Causes found (of 5) | 5, 5, 5 | 4, 3, 2 |
| Basic items raised (of 4) | 4, 4, 4 | 3, 2, 3 |
| Duplicate CBC raised | 3/3 | 1/3 |
| Invented clinical cause | 0/3 | 3/3 ("infection") |
| Numbers not traceable | 0, 0, 0 | 8, 5, 4 |
| Words | 179, 158, 207 | 1417, 1023, 1366 |

An earlier baseline run on the same model returned a degenerate reply (repeated characters); it was discarded and the comparison rerun with fixed settings and retries.
